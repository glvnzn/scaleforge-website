#### Requirements

* Proficiency in NodeJS and Typescript
* Familiarity with backend frameworks (e.g., Express.js, NestJS)
* Solid understanding of database systems, particularly MongoDB
* Knowledge of RESTful and GraphQL API design principles
* Experience with version control systems (e.g., Git)
* Strong problem-solving and analytical skills
* Excellent communication and teamwork abilities

#### Nice to Have

* Experience with Next.js for server-side rendering
* Familiarity with PostgreSQL as a relational database
* Knowledge of containerization and orchestration technologies, such as Kubernetes
* Familiarity with infrastructure-as-code tools, like Terraform
* Understanding of application performance monitoring using tools like New Relic and Elastic Stack
* Experience with cloud platforms (e.g., AWS, Azure, GCP)
* Familiarity with message queues or event-driven architectures
* Understanding of authentication and authorization mechanisms (e.g., OAuth, JWT)
* Proficiency in SQL and database query optimization
* Experience with agile software development methodologies

#### Key Responsibilities

* Design, develop, and maintain scalable and efficient server-side applications
* Collaborate with front-end engineers, product managers, and stakeholders to define and implement API specifications
* Integrate external services and third-party APIs
* Write clean, reusable, and well-documented code
* Conduct thorough testing and debugging of applications
* Collaborate in code reviews and provide constructive feedback to team members
